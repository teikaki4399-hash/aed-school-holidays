# 学校のAEDの休業日を年間行事予定表から取り出す（浦安市の市立小中学校26校）

アイディアソン レポート1（26G1087 鄭家麒）の検証に使ったプログラムとデータです。

## 中身

| ファイル | 内容 | レポートの節 |
|---|---|---|
| `tool/collect_schedules.js` | 市教育委員会の学校一覧から、各校の年間行事予定表（PDF）を集めるツール | 3.1、4.2 |
| `tool/naive_collect.js` | 比較用の素朴な方法（トップページの「年間行事予定」「行事予定」のリンクだけをたどる） | 2.2、4.2 |
| `tool/read_kyuko.js` | 表の中の文字の位置から、「振替休業」「臨時休業」「代休」の欄の日付を求める | 3.2、4.3 |
| `analysis/src.py` | 千葉県のAEDデータで、使える日時が予定などで変わる記録（617件）を原因ごとに分類する | 1.1 |
| `analysis/ambdef.py` | `src.py` が使う「日時が決まらない表現」の判定 | 1.1 |
| `analysis/aed_times_all.tsv` | 千葉県オープンデータサイトのAEDデータから、日時の欄だけを取り出して集計したもの（1列目が件数） | 1.1 |
| `results/kyuko_check.csv` | `read_kyuko.js` で取り出した休校57件を、筆者が表を目で見て確かめた結果（57件すべて正しい） | 4.3 |

## 動かし方

JavaScript のファイルは、どれも Chrome の開発者ツールのコンソールに貼って実行します。
ブラウザの決まりで、PDF やページと同じドメインのページを開いてから実行する必要があります。

1. https://www.city-urayasu.ed.jp/ （浦安市教育委員会の学校一覧）を開く
2. `tool/collect_schedules.js` を実行する（結果は表で表示され、CSV がダウンロードされる）
3. 続けて `tool/naive_collect.js` を実行すると、素朴な方法と比べた結果が表示される
4. `tool/read_kyuko.js` を実行すると、18校の表から休校の日付が表示される

Python のファイルは、`analysis` のフォルダで `python3 src.py` と実行します。
617件と、そのうち学校・園の年間の予定による271件が表示されます。

## データを取った日

- 予定表の収集（手作業とツール）: 2026年10月23日
- 素朴な方法との比較、休校の日付の取り出し: 2026年10月31日
- 東小学校の予定表を載せたページは、10月23日より後に削除されていました。PDFのファイルは残っていたため、`read_kyuko.js` では同じファイルを使っています。

学校のサイトは書き換えられるため、別の日に実行すると結果が変わることがあります。
